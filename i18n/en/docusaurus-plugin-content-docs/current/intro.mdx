# Welcome to PR Review Learning Lab

This unofficial site helps you learn code review, pull requests (PRs), and AI code review through CodeRabbit. It is not the official CodeRabbit website and is not affiliated with CodeRabbit.

## What you will learn

- Why code review matters
- Why AI code review is becoming important
- What CodeRabbit supports on PRs
- How human review and AI review work together
- The basics of GitHub Flow and PRs
- A hands-on development flow using the demo application "Bookmark Inbox"

## Learning Flow

This course does not start with the hands-on exercise immediately. It first explains the purpose of review and the role of AI review, then moves into a practical PR review experience.

```text
Why review is necessary
↓
Why AI review matters
↓
What CodeRabbit helps solve
↓
Experience it in practice
```

## Course Structure

This course is organized into three parts.

## 1. Foundations

Learn the context behind code review and AI code review.

- What is code review?
- What is AI code review?
- What is CodeRabbit?
- GitHub Flow and PRs

## 2. Practice

Use Bookmark Inbox to create a PR and experience a CodeRabbit review.

- The application you will build
- Prepare the development environment
- Implement OGP fetching
- Create a PR
- Experience a CodeRabbit review

## 3. Reflection and Next Steps

Review how to work with AI review and move on to further practice.

- What makes a good review?
- Advanced exercises
- Summary
