# PR Review Learning Labへようこそ

このサイトは、CodeRabbitを題材に、コードレビュー、Pull Request、AIコードレビューの考え方を学ぶための非公式ラーニングサイトです。CodeRabbit公式サイトではなく、CodeRabbit社とは関係ありません。

## このサイトで学ぶこと

- なぜコードレビューが必要なのか
- なぜAIコードレビューが注目されているのか
- CodeRabbitはPull Request上で何を支援するのか
- 人間レビューとAIレビューをどう組み合わせるのか
- GitHub FlowとPull Requestの基本
- デモアプリケーション「Bookmark Inbox」の開発体験

## 学習の流れ

この教材は、すぐにハンズオンへ入るのではなく、先にレビューの目的とAIレビューの位置づけを理解してから、実際のPull Requestレビューを体験する構成にしています。

```text
なぜレビューが必要なのか
↓
なぜAIレビューなのか
↓
CodeRabbitは何を解決するのか
↓
実際に体験する
```

## 章構成

この教材は、3つの章で構成されています。

## 1. 理解編

コードレビューとAIコードレビューの前提を学びます。

- コードレビューとは何か
- AIコードレビューとは何か
- CodeRabbitとは
- GitHub FlowとPull Request

## 2. 実践編

Bookmark Inboxを題材に、Pull Requestを作成し、CodeRabbitレビューを体験します。

- 今回作るアプリケーション
- 開発環境を準備する
- OGP取得機能を実装する
- Pull Requestを作成する
- CodeRabbitレビューを体験する

## 3. 振り返り・発展編

AIレビューとの向き合い方を整理し、次の学習テーマへ進みます。

- 良いレビューとは何か
- 発展課題
- まとめ
