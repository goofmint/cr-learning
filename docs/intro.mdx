# PR Review Learning Labへようこそ

このサイトは、CodeRabbitを題材に、コードレビュー、プルリクエスト（Pull Request。以下PR）、AIコードレビューの考え方を学ぶための非公式ラーニングサイトです。CodeRabbit公式サイトではなく、CodeRabbit社とは関係ありません。

## このサイトで学ぶこと

- なぜコードレビューが必要なのか
- なぜAIコードレビューが注目されているのか
- CodeRabbitはPR上で何を支援するのか
- 人間レビューとAIレビューをどう組み合わせるのか
- GitHub FlowとPRの基本
- デモアプリケーション「Bookmark Inbox」の開発体験

## 学習の流れ

この教材は、すぐにハンズオンへ入るのではなく、先にレビューの目的とAIレビューの位置づけを理解してから、実際のPRレビューを体験する構成にしています。

```text
なぜレビューが必要なのか
↓
なぜAIレビューなのか
↓
CodeRabbitは何を解決するのか
↓
実際に体験する
```

## 章構成

この教材は、3つの章で構成されています。

## 1. 理解編

コードレビューとAIコードレビューの前提を学びます。

- コードレビューとは何か
- AIコードレビューとは何か
- CodeRabbitとは
- GitHub FlowとPR

## 2. 実践編

Bookmark Inboxを題材に、PRを作成し、CodeRabbitレビューを体験します。

- 今回作るアプリケーション
- 開発環境を準備する
- OGP取得機能を実装する

- CodeRabbitレビューを体験する

AIレビューとの向き合い方を整理し、良いレビューの実践のコツを学びます。

- 良いレビューとは何か
