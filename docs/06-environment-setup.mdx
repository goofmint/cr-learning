# 開発環境を準備する

## この章の目的

ハンズオンを進めるために必要な道具を、順番に1つずつそろえます。

この章を終えると、デモアプリ（[Bookmark Demo](https://bookmark-demo.goofmint.workers.dev/)）が自分のパソコンで動き、自分のGitHubリポジトリでCodeRabbitのレビューを受けられる状態になります。

コマンドはそのままコピーして貼り付けながら進められるように書いています。意味がわからないコマンドがあっても、まずはそのまま実行して大丈夫です。

## 全体の流れ

これから次の順番で準備します。上から順にやれば完成します。各項目をクリックすると、その手順に移動できます。

| 手順 | 何をするか |
| --- | --- |
| [手順1](#step-1) | Git をインストールする |
| [手順2](#step-2) | GitHub のアカウントを作る |
| [手順3](#step-3) | デモアプリのリポジトリを Fork（自分用にコピー）する |
| [手順4](#step-4) | Fork したリポジトリを自分のパソコンに持ってくる（clone） |
| [手順5](#step-5) | Node.js をインストールして、必要な部品をそろえる |
| [手順6](#step-6) | Cloudflare のアカウントを作る |
| [手順7](#step-7) | データベース（D1）と画像置き場（R2）を作る |
| [手順8](#step-8) | アプリをローカルで起動して動作確認する |
| [手順9](#step-9) | CodeRabbit を自分のリポジトリで有効にする |

:::note[用語メモ]
**リポジトリ**：ソースコードと、その変更履歴をまとめて保管する場所のことです。GitHub上に置かれます。

**Fork（フォーク）**：他人のリポジトリを、自分のアカウントの下にまるごとコピーすることです。コピーなので、自由に変更しても元のリポジトリには影響しません。

**clone（クローン）**：GitHub上のリポジトリを、自分のパソコンにダウンロードすることです。
:::

## 1. Git をインストールする \{#step-1}

**Git** は、ソースコードの変更履歴を記録するための道具です。これがないと後の手順が進められないので、最初に入れます。

まず、すでに入っているか確認します。ターミナル（Windowsは「コマンドプロンプト」または「PowerShell」、Macは「ターミナル」）を開いて、次を実行します。

```bash
git --version
```

`git version 2.x.x` のようにバージョン番号が表示されたら、すでに入っています。[手順2](#step-2)へ進んでください。

`command not found` のようなエラーが出たら、OSごとに次の方法でインストールします。

### Windows の場合

[Git for Windows の公式サイト](https://gitforwindows.org/) を開き、ダウンロードしたインストーラーを実行します。途中の選択肢はすべて初期設定のまま「Next」で進めて問題ありません。

### Mac の場合

次のコマンドを実行すると、開発ツールのインストール画面が出ます。画面の指示に従ってインストールしてください。

```bash
xcode-select --install
```

### Linux（Ubuntu / Debian）の場合

```bash
sudo apt update
sudo apt install -y git
```

インストール後、もう一度 `git --version` を実行して、バージョン番号が表示されることを確認します。

## 2. GitHub のアカウントを作る \{#step-2}

**GitHub** は、リポジトリをインターネット上に置いて共有できるサービスです。CodeRabbitのレビューもGitHub上で行われるので、アカウントが必要です。

すでにアカウントを持っている人は、この手順をとばして[手順3](#step-3)へ進んでください。

1. [Sign up for GitHub](https://github.com/signup) を開きます
2. メールアドレス、パスワード、ユーザー名を入力します
3. 画面の指示に従って登録を完了します
4. 登録したメールアドレスに届く確認メールのリンクをクリックして、メールアドレスを確認します

無料プランで問題ありません。

次に、パソコンのGitに「自分が誰か」を教えておきます。`Your Name` と `you@example.com` の部分を、自分の名前とGitHubに登録したメールアドレスに置き換えて実行してください。

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

## 3. リポジトリを Fork する \{#step-3}

ハンズオンのベースになるリポジトリは次のものです。

- [https://github.com/goofmint/bookmark-demo](https://github.com/goofmint/bookmark-demo)

このリポジトリを直接変更することはできないので、**自分のアカウントにコピー（Fork）** して使います。

1. ログインした状態で [https://github.com/goofmint/bookmark-demo](https://github.com/goofmint/bookmark-demo) を開きます
2. 画面右上の **「Fork」** ボタンをクリックします  
![bookmark-demo リポジトリのページ。右上に「Fork」ボタンがある](/img/github-repository.jpg)
3. 「Create fork」ボタンをクリックします

少し待つと、`https://github.com/あなたのユーザー名/bookmark-demo` という、自分専用のコピーができます。以降の作業はすべてこの自分のリポジトリで行います。

## 4. 自分のパソコンに clone する \{#step-4}

Fork したリポジトリを、自分のパソコンにダウンロードします。

次のコマンドの `あなたのユーザー名` の部分を、自分のGitHubユーザー名に置き換えて実行してください。

```bash
git clone https://github.com/あなたのユーザー名/bookmark-demo.git
```

ダウンロードが終わったら、できたフォルダの中に移動します。

```bash
cd bookmark-demo
```

:::note[用語メモ]
`cd` は「change directory（ディレクトリを移動する）」の意味で、作業する場所を切り替えるコマンドです。これ以降のコマンドは、すべてこの `bookmark-demo` フォルダの中で実行します。
:::

## 5. Node.js をインストールして部品をそろえる \{#step-5}

このアプリは **Node.js** という、JavaScriptをパソコン上で動かすための実行環境を使います。

まず入っているか確認します。

```bash
node --version
```

`v20.0.0` 以上が表示されればOKです。表示されない、または番号が20より小さい場合は、[Node.js 公式サイト](https://nodejs.org/) から **LTS版** をダウンロードしてインストールしてください（選択肢は初期設定のままで問題ありません）。

次に、アプリが動くために必要な部品（ライブラリ）をまとめてインストールします。`bookmark-demo` フォルダの中で次を実行します。

```bash
npm install
```

:::note[用語メモ]
**npm** は、Node.js用の部品を管理する道具です。`npm install` は、このアプリに必要な部品の一覧（`package.json`）を見て、必要なものを自動でまとめてダウンロードしてくれます。少し時間がかかることがあります。
:::

## 6. Cloudflare のアカウントを作る \{#step-6}

このアプリは **Cloudflare** というサービスの上で動きます。データベースや画像置き場もCloudflareのものを使うので、アカウントが必要です。

すでにアカウントを持っている人は、ログイン手順だけ行ってください。

1. [Cloudflare Dashboard \| Manage Your Account](https://dash.cloudflare.com/sign-up) を開きます
2. メールアドレスとパスワードを入力して登録します
3. 届いた確認メールのリンクをクリックして、メールアドレスを確認します

無料プランで問題ありません。

次に、パソコンからCloudflareを操作できるようにログインします。次のコマンドを実行すると、ブラウザが開いて許可を求められるので「Allow（許可）」をクリックしてください。

```bash
npx wrangler login
```

:::note[用語メモ]
**Wrangler** は、Cloudflareをコマンドで操作するための道具です。`npx` は npm に同梱されているコマンド実行ツール（npm v5.2.0 以降）で、ローカルやグローバルにインストールされたパッケージをそのまま実行できます。npm 自体は[手順5](#step-5)の Node.js インストールで一緒に入ります。
:::

## 7. データベースと画像置き場を作る \{#step-7}

このアプリは、ブックマークを保存する **データベース（Cloudflare D1）** と、OGP画像を保存する **置き場（Cloudflare R2）** を使います。自分専用のものを作ります。

まず、データベース（D1）を作ります。

```bash
npx wrangler d1 create bookmark-demo
```

実行すると、画面に次のような設定が表示されます。

```toml
[[d1_databases]]
binding = "DB"
database_name = "bookmark-demo"
database_id = "ここに長い英数字の文字列が表示されます"
```

この `database_id` の値（`"..."` の中身）をコピーします。

次に、フォルダの中にある `wrangler.toml` というファイルをテキストエディタで開きます。`[[d1_databases]]` の `database_id` の行を探し、その値を、いまコピーした自分の値に書き換えて保存します。

```toml
[[d1_databases]]
binding = "DB"
database_name = "bookmark-demo"
database_id = "コピーした自分の値に置き換える"
migrations_dir = "migrations"
```

:::note[なぜ書き換えるのか]
`database_id` は「どのデータベースを使うか」を指す住所のようなものです。最初は別の人のデータベースを指しているので、自分が作ったデータベースの住所に書き換える必要があります。
:::

書き換えたら、データベースの中に必要な表（テーブル）を作ります。次のコマンドを実行します。

```bash
npx wrangler d1 migrations apply bookmark-demo --local
```

`--local` は「自分のパソコンの中だけで使うデータベースに対して実行する」という意味です。

:::note[用語メモ]
**マイグレーション**：データベースに「こういう表を作る」という設計図を適用する作業のことです。これをしないと、アプリがデータを保存する場所がなくエラーになります。
:::

最後に、OGP画像を保存するための置き場（R2）を作ります。

```bash
npx wrangler r2 bucket create bookmark-demo-ogp
```

これでデータベースと画像置き場の準備ができました。次の手順でローカル起動を確認します。

## 8. ローカルで起動して動作確認する \{#step-8}

まず、アプリをビルド（実行できる形に組み立てる）します。

```bash
npm run build
```

エラーなく終わったら、ローカルサーバーを起動します。

```bash
npm run dev
```

成功すると、ターミナルに `http://localhost:8787` のようなURLが表示されます。そのURLをブラウザで開いてください。Bookmark Demo の画面が表示され、URLを入力してブックマークを追加できれば成功です。

![ローカルで起動したBookmark Demoの画面。URLを入力して「Add Bookmark」ボタンがある](/img/demo-initial.jpg)

サーバーを止めたいときは、ターミナルで `Ctrl + C`（コントロールキーを押しながらC）を押します。

### テストを実行してみる（任意）

このアプリにはテストが用意されています。次のコマンドで実行できます。

```bash
npm test
```

すべてのテストが通れば、環境が正しく整っている目安になります。

## 9. CodeRabbit を有効にする（OSS版） \{#step-9}

最後に、自分のリポジトリで **CodeRabbit** のレビューを受けられるようにします。ここではオープンソース向けの無料の方法（OSS版）で設定します。

1. GitHubにログインした状態で、[CodeRabbit の GitHub Marketplace ページ](https://github.com/marketplace/coderabbitai) を開きます
2. ページにある **「Add」**（追加）ボタンをクリックします
3. プランの選択肢から **「Open Source」** を選びます
4. インストール先として、[手順3](#step-3)で Fork したリポジトリがある自分のアカウントを選びます
5. **「Allow my billing information to be linked with this organization」**（請求情報の連携を許可する）のチェックを入れます
6. 対象リポジトリの選択で、`bookmark-demo` を選びます（「All repositories」でも構いません。あとから変更できます）
7. インストールを完了すると、CodeRabbitのダッシュボードに移動し、リポジトリが表示されます

これで、以降この自分のリポジトリでプルリクエスト（PR）を作ると、CodeRabbitが自動でレビューしてくれるようになります。

:::note[補足]
OSS版の設定手順は記事「[CodeRabbitをOSS向けに無料で導入する](https://qiita.com/goofmint/items/e4ab57e6bf4d8f98ea5c)」でも、画面の図つきで詳しく紹介されています。画面が変わってわかりにくいときは参照してください。
:::

## ここまでのまとめ

これで次の準備が整いました。

- Git と GitHub アカウント
- 自分用に Fork した `bookmark-demo` リポジトリ
- ローカルで動くデモアプリ
- 自分のリポジトリで動く CodeRabbit

次の章からは、このアプリにOGP取得機能を実装し、その変更をプルリクエストにしてCodeRabbitのレビューを受けていきます。
