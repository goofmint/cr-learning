# CodeRabbitのセットアップ

## この章の目的

このあとのPRレビューを体験するために、自分が Fork したリポジトリで **CodeRabbit** を有効にします。ここではオープンソース向けの無料の方法（OSS版）で設定します。

ここまでで「開発環境を準備する」を終え、ローカルで `bookmark-demo` が動いている状態を前提にしています。

## OSS版を有効にする

1. GitHubにログインした状態で、[CodeRabbit の GitHub Marketplace ページ](https://github.com/marketplace/coderabbitai) を開きます
2. ページにある **「Add」**（追加）ボタンをクリックします
3. プランの選択肢から **「Open Source」** を選びます
4. インストール先として、`bookmark-demo` を Fork した自分のアカウントを選びます
5. **「Allow my billing information to be linked with this organization」**（請求情報の連携を許可する）のチェックを入れます
6. 対象リポジトリの選択で、`bookmark-demo` を選びます（「All repositories」でも構いません。あとから変更できます）
7. インストールを完了すると、CodeRabbitのダッシュボードに移動し、リポジトリが表示されます

これで、以降この自分のリポジトリでプルリクエスト（PR）を作ると、CodeRabbitが自動でレビューしてくれるようになります。

:::note[補足]
OSS版の設定手順は記事「[CodeRabbitをOSS向けに無料で導入する](https://qiita.com/goofmint/items/e4ab57e6bf4d8f98ea5c)」でも、画面の図つきで詳しく紹介されています。画面が変わってわかりにくいときは参照してください。
:::
