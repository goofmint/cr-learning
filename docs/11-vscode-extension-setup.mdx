# VS Code機能拡張のセットアップ

## この章の目的

CodeRabbit には、VS Code 上で動く **機能拡張（IDE 拡張）** が用意されています。これを入れると、PRを出す前に **手元で書いたコード** に対してレビューを受けられるようになります。

この章では、その VS Code 拡張をインストールして、ログインし、レビューを受けられる状態にするまでを行います。

## IDEレビューでできること

PRレビューが「PRを作ったあとに GitHub 上で受けるレビュー」だったのに対し、IDEレビューは **コードを書いている途中**、エディタの中でレビューを受けられます。

公式の説明には、おおまかに次のことができると書かれています。

- 未コミット／コミット済みの変更にレビューを受けられる
- 行ごとに、修正の提案や懸念点が表示される
- 簡単な指摘は **ワンクリックで修正** できる
- 複雑な指摘は **AIエージェント**（Claude Code、Cursor、GitHub Copilot など）に投げて直してもらえる

無料プランでも IDE レビューを利用できます。ただし、1日に受けられる回数には上限（レート制限）があります。

:::warning[完全なオフラインでは動きません]
この拡張は、**完全ローカル（オフライン）では動作しません**。手元のアンコミットなファイルもレビューできますが、実際のレビュー処理は **コードをクラウドにアップロードして行われます**。インターネット接続が必要で、社外に出せないコードを扱う場合は、この点に注意してください（社内サーバーで動かしたい場合は、後述の Self Hosted Url を使うセルフホスト版を検討します）。
:::

## 対応エディタ

公式が動作対象として挙げているのは、次の3つです。

- **VS Code**
- **Cursor**
- **Windsurf**

Cursor や Windsurf は VS Code をベースにしたエディタなので、基本的に同じ拡張がそのまま動きます。この章では VS Code を例に進めます。

## 前提

- VS Code がインストールされていること
- CodeRabbit のアカウントが作れること（メールアドレスがあれば作成できます）

[CodeRabbitのセットアップ](coderabbit-setup) の章でリポジトリに CodeRabbit を入れていれば、同じアカウントでログインできます。まだ作っていない場合は、この章の途中で作成できます。

## 1. 拡張をインストールする

VS Code を開き、左側のサイドバーから **拡張機能（Extensions）** のアイコンをクリックします。

検索ボックスに `coderabbit` と入力すると、**「CodeRabbit」**（発行元: **CodeRabbit Inc.**）という拡張が表示されます。これを選び、**「Install」** ボタンを押します。

ブラウザから直接インストールしたい場合は、次のリンクからも入れられます。

- [Visual Studio Marketplace: CodeRabbit](https://marketplace.visualstudio.com/items?itemName=CodeRabbit.coderabbit-vscode)
- 短縮リンク: [https://coderabbit.link/vscode](https://coderabbit.link/vscode)

リンクを開いて「Install」を押すと、VS Code が起動して拡張のインストール画面に切り替わります。

## 2. ログインする

インストールが完了すると、自動で **「Login」ボタン付きのダイアログ** が表示されます。これを押すとログインに進めます。

もしダイアログを閉じてしまった場合は、VS Code の左側にあるアクティビティバー（一番左の縦長のバー）に **CodeRabbit のアイコン** が増えているので、それをクリックし、表示されたパネルから **「Use CodeRabbit for Free」** を選びます。

ログイン操作をすると、

1. ブラウザが起動し、CodeRabbit のログイン画面が開きます
2. アカウントでサインインします（アカウントがない場合はここで作成できます）
3. 認証が終わると、自動で VS Code に戻ります

もしブラウザから VS Code への自動遷移がうまくいかなかった場合は、画面に表示される **success code（成功コード）** をコピーし、VS Code の入力欄に貼り付けます。

ログインに成功すると、CodeRabbit のサイドバーが使える状態になります。

## 3. CodeRabbit のサイドバーを開く

アクティビティバーの **CodeRabbit のアイコン** をクリックすると、画面の左側に CodeRabbit 専用のパネルが開きます。ここからレビューの実行や、指摘の確認を行います。

レビューを実行する具体的な手順は、次の章「[IDEレビューを体験する](experience-ide-review)」で扱います。

## 設定項目

CodeRabbit 拡張には、次のような設定項目が用意されています。今はそのままでかまいません。実際に IDE レビューを体験するときに、必要に応じて調整します。

| 設定項目 | 内容 |
| --- | --- |
| Agent Type | 「Fix with AI」で指摘を直すときに使う AI エージェントを選びます。`Native`（規定）、`Claude Code`、`Claude Code Extension`、`Codex CLI`、`Clipboard`、`Cline`、`Roo`、`Kilo Code`、`Augment Code`、`opencode` のいずれかを指定できます。 |
| Auto Review Mode | コミットしたときに、自動でレビューを始めるかどうかを決めます。デフォルトは `prompt`（コミットのたびに開始するか確認）。ほかに `auto`（毎回自動で開始）、`disable`（自動では開始しない）を選べます。 |
| Auto Start Task | 「Fix with AI」を自動で開始するかどうかのチェックボックスです。 |
| Region | 利用するリージョン（処理を行う地域）です。デフォルトは `US`（米国）。`EU`（欧州）も選べます。 |
| Self Hosted Url | セルフホスト版（自分たちのサーバーで動かす CodeRabbit）を使う場合に、その URL を設定します。通常のクラウド版を使う場合は空のままで問題ありません。 |

### Fix with AI とは

上の `Agent Type` に出てくる **「Fix with AI」** は、CodeRabbit の指摘を AI エージェントに渡して直してもらう機能です。ワンクリックで適用できる小さな修正だけでなく、複雑な修正を Claude Code などのエージェントに任せられます。`Clipboard` を選ぶと、対応するエージェントがなくても、指示文をクリップボードにコピーして手動で渡せます。

## ここまでで整ったもの

- VS Code に CodeRabbit 拡張がインストールされ、サイドバーが開ける
- CodeRabbit アカウントでログイン済み

次の章では、IDEレビューを体験するための題材として、まず手元で **タグ絞り込み機能** を実装します。その変更に対して、この拡張からレビューを受けていきます。
